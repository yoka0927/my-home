一键部署网站

这是无后端部署方式。你只需要登录自己的 Vercel，Vercel 会复制公开模板并自动构建，不需要把 GitHub 密码或 Token 交给本项目。

部署到 Vercel

正在检查开源仓库地址...

  1. 点击上面的按钮，并使用自己的 Vercel 账号登录。
  2. 确认项目名称和构建设置，点击 Deploy。
  3. 部署完成后，进入项目的 Domains 页面查看网站地址。
  4. 编辑器仍在本地运行；编辑完成后，将生成的文件提交到自己的 GitHub，再由 Vercel 自动更新。

如果按钮不可用，请项目维护者先编辑 public/deploy-config.js，填入公开 GitHub 仓库地址。
